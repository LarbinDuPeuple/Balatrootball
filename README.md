# Balatrootball

Roguelike deckbuilder de football : on recrute des footballeurs, on enchaîne des mouvements et des combos (club, nationalité, génération, style) pour battre le mur du gardien adverse.

## Contenu

- `prototype-v0/` : premier prototype jouable en une page HTML (ouvrir `prototype-v0/index.html` dans un navigateur).
  - `src/logic.js` : règles du jeu, sans dépendance au DOM (réutilisable par le futur moteur).
  - `src/sim3.js` : simulation d'équilibrage (`node prototype-v0/src/sim3.js`).

Projet privé : les noms de vrais joueurs sont utilisés pour un usage personnel uniquement.
